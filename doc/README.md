This directory contains doxygen configuration to generate documentation of the ButterflyPACK repository.

Paper-development notes for the distributed H2 algorithms are under
[`h2_paper_notes/`](h2_paper_notes/README.md):

- [optimized Color algorithm](h2_paper_notes/color_algorithm.md)
- [replicated and component-owner CA algorithms](h2_paper_notes/ca_algorithm.md)

Performance of the GPU HODLR backend (`HODLR_use_gpu`) on Perlmutter:
[`gpu_hodlr/performance.md`](gpu_hodlr/performance.md).

Environment variables of the H2 code and the GPU backends (`BPACK_CHECK`,
`BPACK_TRACE`, device memory, GPU-aware MPI):
[`environment_variables.md`](environment_variables.md).

The partial H2 factorization (`H2_partial`): eliminate a front's leading
points and serve its partial solves and the Schur complement's entries and
products (`c_bpack_partial_*`, `c_bpack_extractelement`), on the CPU and the
GPU: [`h2_partial_factorization.md`](h2_partial_factorization.md).

The matrix's entries on the GPU (`H2_use_gpu`, `HODLR_use_gpu`): how to write
and register a GPU evaluator of the application's kernel, from C++, C,
Fortran or Python: [`gpu_kernels.md`](gpu_kernels.md).

Launching on Perlmutter: an exported `LD_PRELOAD` of the library puts every
OpenMP thread of a rank on one core when a wrapper (`time`, `bash -c`) runs
first; and which BLAS to use with the H2 code:
[`running_on_perlmutter.md`](running_on_perlmutter.md).

Using CMAKE, the documentation can be generated by:  
```
mkdir build ; cd build;
cmake .. \
	-DCMAKE_Fortran_FLAGS="" \
	-DCMAKE_CXX_FLAGS="" \
	-DTPL_BLAS_LIBRARIES="${BLAS_LIB}" \
	-DTPL_LAPACK_LIBRARIES="${LAPACK_LIB}" \
	-DTPL_SCALAPACK_LIBRARIES="${SCALAPACK_LIB}" \
	-DTPL_ARPACK_LIBRARIES="${ARPACK_LIB}" \
	-DBUILD_SHARED_LIBS=ON \
	-DCMAKE_Fortran_COMPILER=mpif90 \
	-DCMAKE_CXX_COMPILER=mpicxx \
	-DCMAKE_C_COMPILER=mpicc \
	-DCMAKE_INSTALL_PREFIX=. \
	-DCMAKE_BUILD_TYPE=Release \
	-Denable_doc=ON
make doc
```
The documentation will be generated at build/doc/html or build/doc/latex. Note that once "Denable_doc=ON" is enabled, the code cannot be compiled as the source files are inserted with doxygen markers.
